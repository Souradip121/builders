# Free AI agent courses from Microsoft, Hugging Face, OpenAI and Google

Part 2 of "Anthropic's agent playbook is free on GitHub". Star counts as shown on GitHub on 2026-11-24; none of these repos are archived.

## 1. microsoft/ai-agents-for-beginners (80.9k stars)
https://github.com/microsoft/ai-agents-for-beginners
"18 Lessons to Get Started Building AI Agents". Open `00-course-setup`, then `01-intro-to-ai-agents`.

## 2. huggingface/agents-course (35.4k stars)
https://github.com/huggingface/agents-course · course: https://huggingface.co/learn/agents-course
Free with no deadline, and "the certification process is completely free". Fundamentals certificate: finish Unit 1. Completion certificate: Unit 1 + one use-case assignment + the final challenge. Start at Unit 0.

## 3. openai/openai-agents-python (30.9k stars)
https://github.com/openai/openai-agents-python
"A lightweight, powerful framework for multi-agent workflows." Open `examples/basic/hello_world_jupyter.ipynb` first.

## 4. google/adk-python (22.3k stars)
https://github.com/google/adk-python · docs: https://adk.dev
A code-first Python toolkit for building, evaluating and deploying agents. Samples in `contributing/samples/`.

## 5. google/adk-samples (10.7k stars)
https://github.com/google/adk-samples
"A collection of agent recipes, reference patterns, and vertical plugins built with ADK." Start in `core/`.

## 6. microsoft/generative-ai-for-beginners (124.1k stars)
https://github.com/microsoft/generative-ai-for-beginners
"21 Lessons, Get Started Building with Generative AI." Lesson 17 is the agents lesson.

## Suggested 3-week plan
- Week 1: Microsoft lessons 1–6 + Hugging Face Unit 1 (get the free certificate).
- Week 2: build one agent with the OpenAI Agents SDK *or* Google ADK, not both.
- Week 3: copy one recipe from adk-samples/core, change it for your own use case, and ship it.

Also good: google-gemini/cookbook (`quickstarts/Get_started.ipynb`).
