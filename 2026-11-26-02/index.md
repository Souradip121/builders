# Internship-ready by summer 2027: the 5-month roadmap

For 2nd/3rd-year CS students. One folder a month, December 2026 to April 2027. Everything below is free to use.

## 01 · December: DSA foundations
- **NeetCode practice** (https://neetcode.io/practice): problem lists including Blind 75, NeetCode 150 and NeetCode 250, grouped by pattern. The practice page is free; some problems are marked Pro. Go topic by topic, one problem a day.
- **CS50x 2026** (https://cs50.harvard.edu/x/): Harvard's intro to CS, free via OpenCourseWare. Weeks 0–10 cover Scratch, C, Python, SQL, HTML/CSS/JavaScript and Flask, then a final project. Do it if your basics feel shaky.
- **GitHub Student Developer Pack** (https://education.github.com/pack): free GitHub Pro while you're a student, plus Copilot Student for verified students.

## 02 · January: ship project 1
- **The Odin Project** (https://www.theodinproject.com/paths): free, open source curriculum. Start with Foundations, then the Full Stack JavaScript path (7 courses) or Full Stack Ruby on Rails (8 courses).
- Build a CRUD app someone else can use. Deploy it and write a README with a screenshot and setup steps.

## 03 · February: first open source PRs
- **First Contributions** (https://github.com/firstcontributions/first-contributions): a practice repo that walks you through fork → clone → branch → commit → push → pull request.
- **good-first-issue topic** (https://github.com/topics/good-first-issue): 3,273 public repos tagged for beginners when checked. Read CONTRIBUTING.md, comment on an issue before starting, keep PRs small. Docs fixes count.

## 04 · March: project 2 + resume
- Project 2 should solve a real problem (for your college, a club, a friend's shop).
- One-page resume: links to both projects and your PRs at the top.
- **Google Summer of Code**: in 2026, contributor applications ran 16–31 March and coding began 25 May. The 2027 dates aren't published yet: watch https://developers.google.com/open-source/gsoc/timeline.

## 05 · April: apply and interview
- Apply on company careers pages every week and track each application in a sheet.
- Do mock interviews with a friend. Practise explaining each project in 2 minutes.
- Re-solve the NeetCode topics you got wrong.
