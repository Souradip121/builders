# Build your own Git, Redis and a browser: the free path

This week Ladybird, a browser engine written from scratch, released its first alpha. You don't need to build a browser on day one. These free, step-by-step projects show you how real software works by making you rebuild it.

## 1. build-your-own-x (the index)
https://github.com/codecrafters-io/build-your-own-x
- A curated list of tutorials to recreate technologies from scratch: Git, databases (including Redis), web browsers, programming languages, shells and more, in many languages.
- About 565K stars, CC0 licence. Free.
- How to use it: pick ONE tool you use every week, pick a tutorial in a language you know, and finish it before starting another.
- Note: the repo is run by CodeCrafters, whose own guided challenges (https://codecrafters.io/pricing) have a limited free tier and paid membership plans. Everything else in this guide is free.

## 2. Write yourself a Git (wyag)
https://wyag.thb.lt/
- Rebuild a simplified Git in Python 3.10+, standard library only.
- 15 commands, including init, hash-object, cat-file, log, ls-tree, checkout, tag, status, add, commit.
- Best first project: after it, `.git/` stops being magic.

## 3. Build Your Own Redis with C/C++
https://build-your-own.org/redis/
- "The full book is free in web version": 14 chapters, from socket programming and an event loop to hashtables, sorted sets, TTL expiry and a thread pool.
- The ebook and paperback are paid and optional.
- Good second project once you know some C.

## 4. Web Browser Engineering
https://browser.engineering/
- Build a basic but complete browser, from networking to JavaScript, in a couple thousand lines of Python 3.
- Free to read online; also published by Oxford University Press as an open-access book (CC BY-NC-ND 4.0).

## 5. Crafting Interpreters
https://craftinginterpreters.com/
- Build an interpreter for the Lox language twice: jlox in Java, then clox in C.
- "Read the whole book for free. Really." Print (640 pages) and ebooks are paid.

## 6. Ladybird (the real-world example)
https://ladybird.org/ · https://github.com/LadybirdBrowser/ladybird
- A new browser engine written from scratch, not a fork of Chromium, Gecko or WebKit. Backed by a 501(c)(3) non-profit. BSD-2-Clause licence.
- Alpha builds since 23 November 2026 for macOS and Linux, aimed at early adopters who don't mind bugs.
- How to help: test sites and report what breaks, read the "Getting involved" guide and CONTRIBUTING.md in the repo, and join the Discord linked from the site.

## How to do this without quitting
1. One project at a time, in a language you already know.
2. Type the code, don't paste it.
3. Push to GitHub with a README on what you learned. That repo is a great interview story.
