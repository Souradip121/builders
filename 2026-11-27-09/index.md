# THIS IS GOLD: the 1st-year CS roadmap (Dec 2026 to May 2027)

For 1st-year CS students. Six folders, one a month. Every resource below is free.

## 01 · December: one language, properly
- **CS50x 2026** (https://cs50.harvard.edu/x/): Harvard's intro to CS, free via OpenCourseWare (an edX account is needed only if you want your problem sets graded). Weeks 0–6 take you from Scratch to C to Python. Do one week at a time and finish each problem set yourself.
- Pick C or Python as your main language and stop switching. Depth beats a list of languages on your resume.
- Note: CS50's honesty policy forbids making problem-set solutions available to anyone, so keep those out of public repos.

## 02 · January: git + GitHub
- **GitHub Hello World** (https://docs.github.com/en/get-started/start-your-journey/hello-world): repositories, branches, commits and pull requests in one short exercise.
- **Profile README** (https://docs.github.com/en/account-and-profile/how-tos/profile-customization/managing-your-profile-readme): create a public repo named exactly like your username, tick "Add README", and write 3 lines: who you are, what you're learning, what you've built.
- Commit your own practice code every day you code.

## 03 · February: first small projects
- **The Odin Project** (https://www.theodinproject.com/paths): a free, open source curriculum. Start with Foundations (HTML, CSS, JavaScript basics).
- **freeCodeCamp Responsive Web Design** (https://www.freecodecamp.org/learn): free, with 5 certification projects and a free 50-question exam for a verified certification.
- Build 3 tiny things: a CLI to-do list, a quiz, a personal page. Each repo gets a README with a screenshot.

## 04 · March: DSA basics, slowly
- **NeetCode practice** (https://neetcode.io/practice): problem lists (Blind 75, NeetCode 150) grouped by pattern, with free video explanations; some features are Pro. In year 1, stick to the easy arrays, strings and hashing problems.
- Re-watch CS50 Weeks 3 (Algorithms) and 5 (Data Structures).
- 3 problems a week is enough. Consistency over volume.

## 05 · April: a club + your first hackathon
- Join your college's coding or dev club. Ask seniors which hackathons they went to.
- **Devfolio** (https://devfolio.co/hackathons) lists open and upcoming Indian hackathons, online and offline.
- **MLH** (https://www.mlh.com/seasons/2027/events) lists the 2027 season, including events in India.
- Check each event's own page for dates, team size and eligibility. Go to learn and ship something small.

## 06 · May: build, deploy, write
- Pick a real problem (your hostel, a club, a friend's shop) and build one project for it.
- **GitHub Pages** (https://pages.github.com/): free hosting for static sites from a public repo on GitHub Free. Create `username.github.io` for your personal site.
- Write a short post on what you built and what broke. Pin the repo on your profile.
