# 5 free certificates that look good on a resume (₹0, Nov 2026)

Each of these costs ₹0 to earn and gives you a certificate, badge or credential you can link on LinkedIn. Paid upgrades exist for some; you don't need them. Checked on 27 Nov 2026.

## 1. CS50x: the free CS50 certificate
https://cs50.harvard.edu/x/ · certificate rules: https://cs50.harvard.edu/x/certificate/
- What you get: a free **CS50 Certificate** issued by CS50 itself. (A *verified* certificate from edX is a separate paid option.)
- How: CS50x 2026 is 11 weeks of material (Week 0–10). Submit every problem set and the final project with **at least 70% on each**. Submitting needs a free edX account.
- Claim: a link appears in your CS50 Gradebook; log in with GitHub and type the name to print. Download it.
- Not done by 31 Dec? Per the FAQ, your 2026 work carries over into 2027.

## 2. freeCodeCamp verified certifications
https://www.freecodecamp.org/learn
- What you get: a verified certification, free. freeCodeCamp says it has "always been free".
- How (new format, e.g. Responsive Web Design): finish the modules and quizzes, build **5 certification projects**, then pass a **50-question exam** in their open-source exam app on a laptop (one attempt a week).
- Current courses: Responsive Web Design, JavaScript, Frontend Libraries, Python, Relational Databases, Backend JavaScript.

## 3. AWS Educate: free cloud badges
https://aws.amazon.com/education/awseducate/
- What you get: free self-paced cloud training, hands-on labs and **shareable digital badges**.
- Who: anyone 13+ with an email address. **No credit card needed.**
- Start with the getting-started courses (Compute, Storage, Networking, Databases, Cloud Operations).

## 4. Cisco Networking Academy: Python Essentials 1 badge
https://www.netacad.com/courses/python-essentials-1
- The course is free. Pass the final test and Cisco (with the OpenEDG Python Institute) issues a **Credly badge**: https://www.credly.com/org/cisco/badge/python-essentials-1.1
- Also free on NetAcad: Introduction to Cybersecurity (https://www.netacad.com/courses/introduction-to-cybersecurity).

## 5. Microsoft Applied Skills
https://learn.microsoft.com/en-us/credentials/applied-skills/
- What you get: a Microsoft-verified credential for one specific skill. You do real tasks in a live lab instead of a multiple-choice exam. Microsoft describes it as "a free, interactive lab-based assessment".
- Beginner pick for CS students: **Get started with classes, properties, and methods in C#** (https://learn.microsoft.com/en-us/credentials/applied-skills/get-started-with-classes-properties-and-methods-in-c-sharp/). Prep with the free Learn modules linked on that page.
- After you launch a lab, you wait **72 hours** before you can launch it again. Note: Microsoft *certification* exams (like AZ-900) are paid, priced by country, with student discounts after verification.

## Add any of them to LinkedIn
1. Profile → Add profile section → Licences & certifications.
2. Name, issuing organisation (CS50, freeCodeCamp, AWS, Cisco, Microsoft), issue date.
3. Paste the credential URL so anyone can verify it.
4. Mention the project you built for it under Projects; that's what interviewers ask about.
