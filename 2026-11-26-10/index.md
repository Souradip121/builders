# The ₹0 full-stack roadmap: 8 steps, 8 projects

The order I'd learn full-stack web development from scratch in 2027. One free resource per step and one small project, so you finish each step with something you can link to. Push every project to GitHub as you go.

| Step | Learn | Free resource | Build |
|---|---|---|---|
| 1 | HTML + CSS | [MDN: Learn web development](https://developer.mozilla.org/en-US/docs/Learn_web_development) | A one-page portfolio |
| 2 | JavaScript | [The Odin Project: Foundations](https://www.theodinproject.com/paths/foundations/courses/foundations) | Its Rock Paper Scissors and Calculator projects |
| 3 | Git | [Pro Git book](https://git-scm.com/book/en/v2) (free online, chapters 1–3 are enough to start) | Every project so far, on GitHub |
| 4 | React | [react.dev/learn](https://react.dev/learn) | The [tic-tac-toe tutorial](https://react.dev/learn/tutorial-tic-tac-toe), then your portfolio in React |
| 5 | Backend (Node + Express) | [Full Stack Open, Part 3](https://fullstackopen.com/en/part3) | The course's phonebook REST API |
| 6 | SQL + PostgreSQL | [PostgreSQL's official tutorial](https://www.postgresql.org/docs/current/tutorial.html) | Move your API's data into Postgres |
| 7 | Auth | [Full Stack Open, Part 4: token authentication](https://fullstackopen.com/en/part4/token_authentication) | Login with bcrypt-hashed passwords and JSON web tokens |
| 8 | Deploy | [Full Stack Open: deploying to the internet](https://fullstackopen.com/en/part3/deploying_app_to_internet) + [Render](https://render.com/pricing) | Your full app on a live URL |

## Notes on each resource
- **MDN** is Mozilla's reference for HTML, CSS and JavaScript. The Learn section is a structured course, free.
- **The Odin Project** says its full-stack curriculum is free and maintained by an open-source community. Foundations covers HTML, CSS, JavaScript basics and Git, with projects (Recipes, Landing Page, Rock Paper Scissors, Etch-a-Sketch, Calculator).
- **Pro Git** is the whole book, free to read online under a Creative Commons licence.
- **react.dev** is React's official docs. Start with the Learn section and the tic-tac-toe tutorial.
- **Full Stack Open** (University of Helsinki) is "totally free of charge", and you can get a certificate and even ECTS credits for free. Part 3 builds a REST API with Node.js and Express (it stores data in MongoDB); Part 4 adds users and token login.
- **Prefer Python?** Swap steps 5–7 for [CS50's Web Programming with Python and JavaScript](https://cs50.harvard.edu/web/) (free on OpenCourseWare): Django, SQL, models and migrations.
- **PostgreSQL tutorial** is Part I of the official docs: concepts, tables, queries, joins.

## The ₹0 catch (Render, checked today)
- The Hobby workspace is $0/month + compute. Free web services exist, but they **spin down after 15 minutes** without traffic and take about a minute to wake up.
- Render gives 750 free instance hours per workspace per month.
- **Free Render Postgres databases expire 30 days after creation.** Fine for a demo, not for data you need to keep.
- Static sites deploy for free.

## How I'd run it
1. One step at a time. Don't touch React until vanilla JS feels boring.
2. Finish the project before moving on. A live link beats a course list.
3. Write a 3-line README for each repo: what it does, how to run it, what you learned.
