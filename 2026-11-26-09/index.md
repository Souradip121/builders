## What to build
- **#BuildHybridAI:** an app that runs AI prompts on-device and falls back to the cloud, using the Firebase AI Logic hybrid inference SDK, on Web (Chrome), Android or iOS. Grand Prize $10,000, plus $3,000 for the best app on each platform. Existing apps count if significantly updated. Text inference with Firebase AI Logic is free within usage limits.
- **Deck the Pixels:** no code. Design an ugly holiday sweater, add yourself, and turn it into a holiday card in Photoshop with Nano Banana. 1st place $8,000. Photoshop's free web version gives 5 generations a day, so plan ahead.
- **Learn AR with SPECS:** design an AR Lens for glasses and let a coding agent build it in Lens Studio. You don't need the glasses: it runs in Lens Studio's preview. 1st $1,250, 2nd $750, 3rd $500.
- **Reddit's Game of the Day:** a daily game on Devvit Web (Reddit's Developer Platform), with React, Phaser, three.js or a game engine. Best Daily Game wins $15,000.
- **promptwaves:** a 24-hour online sprint. The problem statement drops when the clock starts. ₹40,000 in cash prizes plus free domain names.
- **GenHacks:** any new software or hardware project in one of four tracks (Healthcare & Environmental; Robotics & IoT; AI, Agentic Systems, Cybersecurity & Dev Tools; Open). 1st place CAD 500 cash plus sponsor credits.

## How to enter (Devpost ones)
1. Make a free Devpost account and click "Join hackathon".
2. Read the Rules tab: the judging criteria tell you what to build.
3. Record a short demo video early. Most judges watch it first.
4. Submit a few hours before the deadline.
