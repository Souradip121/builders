# AI coding plans compared (November 2026)

Prices in USD per month from each official pricing page. Usage limits are what the page states; most don't publish exact caps.

|---|---|---|---|

| | **Pro** | **$20** ($17/mo billed yearly, $200 up front) | Claude Code included; more models; Fable paid with usage credits |
| | Max | $100 | 5x Pro usage |

| | Go | $8 | Codex for lightweight tasks |

| | **Pro** | **$10** | Unlimited completions, $15 of monthly AI credits, cloud agent, code review |

| | **AI Pro** | **$19.99** (₹1,950 in India) | Entry rate limits to the agent model in Google Antigravity, 4x Free usage, 5 TB |

| | Plus | $8 | Cursor + Grok; only Grok models |
| | **Premium** | **$30** | 4x Plus usage, cloud agents and automations, AI code reviews, third-party models at API list price |

## What changed this autumn
- Cursor's pricing page no longer shows a Pro plan; its plans are now Plus, Premium, Super ($100) and Ultra ($200).
- GitHub Copilot meters usage in AI credits.

## How to choose
1. Mostly agent work in a terminal or IDE: one $20 plan with a coding agent (Claude Pro or ChatGPT Plus).
2. Mostly autocomplete: Copilot Pro at $10, or Copilot Free to start.
3. Students: check GitHub Education first; verified students get Copilot Student free.
4. Upgrade only when you hit the limit every week, not once.
