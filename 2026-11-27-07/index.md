# 5 campus programs that look great on a resume (2027 edition)

All five are free to join. Each one gives you something you can put on a resume: a title, a team you led, or real shipped work. Details checked on the official pages on 26 Nov 2026.

## 1. Microsoft Student Ambassadors
- **Link:** https://learn.microsoft.com/en-us/training/student-hub/become-a-student-ambassador (register at https://studentambassadors.com)
- **What it is:** Microsoft's student community, now open to students of every degree field. **No application required.**
- **How it works:** Register (under 5 minutes), watch for the next-steps email, finish the registration activities (e.g. sharing content or hosting a learning playlist on campus), then get invited and onboarded.
- **Perks once you're in:** Microsoft 365, Visual Studio Enterprise, **$150 USD of Azure credits every month**, badges, swag, plus short rotations with Microsoft teams.

## 2. GitHub Campus Experts
- **Link:** https://githubcampus.expert/ · how to apply: https://docs.github.com/en/education/about-github-education/use-github-at-your-educational-institution/applying-to-be-a-github-campus-expert
- **What it is:** GitHub trains students to build the tech community on their campus.
- **Who can apply:** 18+, a GitHub user for at least 6 months, enrolled in higher education with more than 1 year left before graduating, student status verified through the GitHub Student Developer Pack.
- **When:** applications open **every July** for a month. Process: application form, then a video resume, then training and onboarding if accepted.
- **Do now:** get the Student Pack verified and stay active on GitHub so you qualify by July 2027.

## 3. Google Developer Groups (GDG) on Campus
- **Link:** https://developers.google.com/community/gdg · lead a chapter: https://app.advocu.com/gdg/join · find one: https://gdg.community.dev/
- **What it is:** Google's student developer clubs (the old GDSC). Chapters run events, workshops and build projects with Google tech.
- **How to get in:** check the chapter directory for your college. Core-team recruitment is run by each chapter. No chapter yet? Use "Lead a GDG on Campus".

## 4. AWS Student Builder Groups (formerly AWS Cloud Clubs)
- **Link:** https://builder.aws.com/community/cloud-clubs
- **Who:** any learner enrolled in a post-secondary institution, aged 18+. Groups already run in India (Chennai, Bengaluru, Indore, Ahmedabad, Coimbatore, Thane, Ghaziabad and more).
- **Leader perks:** AWS Credits, AWS Certification exam vouchers, swag and direct contact with AWS professionals.
- **How:** join a nearby group via its Meetup page, or apply to start one at your college from the same page.

## 5. MLH Fellowship
- **Link:** https://fellowship.mlh.com/ · Software Engineering track: https://fellowship.mlh.com/programs/software-engineering
- **What it is:** a fully remote, 12-week internship alternative. You work in a pod of 10 on a real partner project, make PRs and get code review from mentors.
- **Rules:** 18+, at least 20 hours a week for all 12 weeks. An educational stipend is given in select programs (amount not published).
- **Next batch:** Spring 2027 runs **25 Jan to 16 Apr 2027**. Applications are rolling and close a few weeks before the start, so apply early.

## How to make it count on your resume
Write what you did, not just the title: "Ran 4 workshops for 120+ students" beats "GDG member".
