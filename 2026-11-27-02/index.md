# Your first merged PR in 30 days: the 4-week roadmap

For CS students who have never contributed to open source. One folder a week. Everything here is free.

## week-1-basics/
- Learn the loop: clone, branch, commit, push, pull request.
- **First Contributions** (https://github.com/firstcontributions/first-contributions): a practice repo (57K+ stars) that walks you through fork → clone → branch → commit → push → pull request by adding your name to `Contributors.md`. It also covers common errors and GUI tools if you don't want the command line yet.
- Done when: your practice PR is open.

## week-2-pick-a-project/
- **goodfirstissue.dev** (https://goodfirstissue.dev/): curates easy issues from popular projects; browse by language.
- **Up For Grabs** (https://up-for-grabs.net/): projects with tasks set aside for new contributors.
- **good-first-issue topic** (https://github.com/topics/good-first-issue): 3,292 public repos when checked.
- `good first issue` is one of GitHub's default labels, and issues with it show up on a repo's contribute page: `https://github.com/OWNER/REPO/contribute`.
- Pick a project you actually use. Read README and CONTRIBUTING.md, then get it running locally and run the tests.
- Done when: tests pass on your machine.

## week-3-first-pr/
- Comment on the issue before you start, so nobody duplicates work.
- Keep it small: a docs fix, a missing test, one clear bug.
- Fill in the PR template, link the issue it fixes, explain what you changed and how you tested it.
- Done when: CI is green and the PR is open.

## week-4-review/
- Reply to every review comment. Push fixes to the same branch.
- Be patient and polite; maintainers review in their spare time.
- Done when: your PR says Merged. Then pick issue #2 in the same repo.

## Don't open AI slop
- Look for an AI policy in CONTRIBUTING.md or the docs before you prompt anything.
- **curl's rule** (https://curl.se/dev/contribute.html): AI-assisted code can be accepted, but it must follow the coding standards, be documented and include tests; "if someone can spot that the contribution was made with the help of AI, you have more work to do."
- On 13 Feb 2026 GitHub gave maintainers settings to turn pull requests off or restrict them to collaborators (https://github.blog/changelog/2026-02-13-new-repository-settings-for-configuring-pull-request-access/). Low-effort PRs make repos close the door.
- Run and test every change locally. If you can't explain a line, don't submit it.

## next-step/
- **Google Summer of Code** (https://summerofcode.withgoogle.com/): a 12+ week mentored open source project. 2027 dates aren't published yet; watch https://developers.google.com/open-source/gsoc/timeline.
- **Outreachy** (https://www.outreachy.org/): paid, remote, 3-month open source internships for people underrepresented in tech; $7,000 USD total stipend. Applicants make contributions during the application period.
- **LFX Mentorship** (https://mentorship.linuxfoundation.org/): paid, mentored contributions to Linux Foundation projects; stipends vary by country.
